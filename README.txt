IMPORTANT: This build removes HTML form submission from the login screen. The Sign in control is a JavaScript button, so it cannot navigate to localhost:8080/?

1. Close any old TheatreFlow server windows.
2. Extract this ZIP into a NEW folder.
3. Open app\START_WINDOWS.bat.
4. Keep the black server window open.
5. Open http://localhost:8080 in Chrome.
6. If an old page is cached, press Ctrl+Shift+R once.
